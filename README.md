# Brain Stroke Prediction & Web-Based Healthcare Platform

## Overview
This project is an AI-powered web-based platform for predicting brain strokes from CT and MRI scans. It leverages deep learning models to detect potential brain damage and provides a web interface for managing patient data and visualizing results.

## Features
- Automated stroke detection using deep learning models
- Web-based interface for managing patient data
- Visualization of scan analysis results
- User-friendly design tailored for healthcare professionals
- Designed for local deployment with potential for future online access

## Technologies Used
- Deep Learning & AI: MobileNet, DenseNet121, U-Net, TensorFlow, Keras, OpenCV  
- Web Development: HTML, CSS, JavaScript, PHP, MySQL  
- Data Processing: Python, Pandas, NumPy  
- Evaluation: Confusion Matrix, ROC Curve

## Project Structure
- /models → trained AI models  
- /web → front-end and back-end code for the platform  
- /data → sample MRI/CT images (anonymized)  
- /notebooks → Python notebooks for data preprocessing, model training, and evaluation

## Deployment
- Runs locally for development and testing  
- Can be deployed on a public server for future accessibility
